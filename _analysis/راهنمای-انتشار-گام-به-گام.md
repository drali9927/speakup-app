# راهنمای انتشار — گام به گام

کارهایی که فقط شما می‌توانید انجام دهید، به ترتیبی که باید انجام شوند.
ترتیب مهم است: هر گام به گام قبلی وابسته است.

زمان تقریبی کل: **یک تا دو هفته**، که بیشترش انتظار برای تأیید حساب‌هاست
نه کار کردن.

---

## گام ۱ — کلید امضای اپ ⏱ ۱۰ دقیقه

**چرا اول از همه:** هش پیامک و ارسال به کافه‌بازار هر دو به این نیاز
دارند. تا این نباشد، آن دو قابل نهایی شدن نیستند.

### ۱-۱. کلید را بسازید

این را در ترمینال اجرا کنید:

```bash
cd ~/Desktop && keytool -genkeypair -v -keystore speakup-release.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
```

چند سؤال می‌پرسد:

| سؤال | چه بنویسید |
|---|---|
| Enter keystore password | یک رمز قوی — **جایی امن ذخیره‌اش کنید** |
| Re-enter new password | همان |
| What is your first and last name? | نام خودتان یا نام شرکت |
| organizational unit / organization | می‌توانید خالی بگذارید (Enter) |
| City / State / Country code | مثلاً `Tehran` / `Tehran` / `IR` |
| Is CN=… correct? | `yes` |

### ۱-۲. رمزها را جایی بنویسید که به گیت‌هاب نرود

این فایل را بسازید یا بازش کنید:

```bash
open -e ~/.gradle/gradle.properties
```

و این چهار خط را اضافه کنید (مقدارها را با مال خودتان عوض کنید):

```properties
speakup.storeFile=/Users/alikavyani/Desktop/speakup-release.jks
speakup.storePassword=رمزی که ساختید
speakup.keyAlias=upload
speakup.keyPassword=همان رمز
```

> ⚠️ **در پوشه پروژه ننویسیدشان.** فایل `android/gradle.properties`
> داخل مخزن است و به گیت‌هاب می‌رود؛ رمزتان عمومی می‌شود. فایل پوشه
> خانگی که بالا گفتم هرگز در مخزن نیست.

### ۱-۳. ⚠️ مهم‌ترین جمله این سند

**از فایل `speakup-release.jks` پشتیبان بگیرید و گمش نکنید.**

کافه‌بازار به‌روزرسانی اپی را که با کلید دیگری امضا شده نمی‌پذیرد. گم
شدن این فایل یعنی مجبورید اپ را از صفر منتشر کنید و **همه کاربران فعلی
را از دست بدهید**. راه برگشتی هم ندارد.

پشتیبان روی یک حافظه جدا، و رمزش جای دیگری. نه در ایمیل، نه در تلگرام.

## گام ۲ — دامنه و سرور ⏱ ۱ تا ۳ روز

### ۲-۱. دامنه بخرید

از ایرنیک یا هر فروشنده داخلی. چیزی مثل `speakup.ir`.

### ۲-۲. سرور بخرید

مشخصاتش را در [سرور-چی-بخرم.md](سرور-چی-بخرم.md) نوشتم: **۲ هسته، ۲
گیگ رم، ۵۰ گیگ SSD**. آروان، لیارا یا پارس‌پک.

### ۲-۳. دامنه را به سرور وصل کنید

در پنل دامنه، یک رکورد `A` بسازید:

```
api.speakup.ir  →  آی‌پی سرور
```

### ۲-۴. HTTPS

اپ در نسخه منتشرشده **فقط** HTTPS می‌پذیرد. ساده‌ترین راه، Caddy است
که خودش گواهی می‌گیرد و تمدید می‌کند. روی سرور:

```bash
sudo apt install caddy
```

و فایل `/etc/caddy/Caddyfile`:

```
api.speakup.ir {
    reverse_proxy localhost:8099
}
```

بعد `sudo systemctl restart caddy`. همین. گواهی خودکار گرفته می‌شود.

> **از این آدرس به هاست‌کارتان کمک بگیرید.** این تنها گام سند است که
> اگر با لینوکس راحت نیستید، بهتر است کسی کنارتان باشد.

## گام ۳ — سرویس پیامک ⏱ ۲ تا ۵ روز (بیشترش انتظار تأیید)

### ۳-۱. حساب کاوه‌نگار

در kavenegar.com ثبت‌نام کنید و **خط خدماتی** بخرید (نه تبلیغاتی —
پیامک کد ورود باید خدماتی باشد وگرنه ارسال نمی‌شود).

تأییدش معمولاً یکی دو روز طول می‌کشد و مدارک شرکت یا کارت ملی می‌خواهد.

### ۳-۲. هش پیامک را بگیرید

**این گام به کلید گام ۱ نیاز دارد.** در ترمینال:

```bash
cd "/Users/alikavyani/Desktop/speak up" && tools/sms_app_hash.sh ~/Desktop/speakup-release.jks upload ir.speakup.app
```

یک رشته ۱۱ کاراکتری می‌دهد، مثلاً `fsNl0lc7Swe`.

### ۳-۳. الگو را در پنل کاوه‌نگار ثبت کنید

متن الگو دقیقاً این شکل، با هش خودتان در خط آخر:

```
کد ورود اسپیک‌آپ: %token
fsNl0lc7Swe
```

> ⚠️ اگر هش اشتباه باشد **هیچ خطایی نمی‌بینید** — فقط کد خودکار پر
> نمی‌شود و کاربر باید دستی تایپش کند. حتماً روی یک گوشی واقعی امتحان
> کنید.

## گام ۴ — تنظیمات سرور ⏱ ۱۵ دقیقه

روی سرور، این متغیرها را تنظیم کنید:

```
NODE_ENV=production
JWT_SECRET=<یک رشته تصادفی حداقل ۳۲ کاراکتری>
SMS_PROVIDER=kavenegar
KAVENEGAR_API_KEY=<از پنل کاوه‌نگار>
KAVENEGAR_TEMPLATE=<نام الگویی که ثبت کردید>
ADMIN_TOKEN=<یک رشته تصادفی دیگر>
BAZAAR_ACCESS_TOKEN=<گام ۵>
```

برای ساختن رشته تصادفی:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

سه نکته:

- **`JWT_SECRET` را یک بار درست انتخاب کنید.** عوض کردنش یعنی همه
  کاربران از حساب خارج می‌شوند.
- **`ADMIN_TOKEN` را تازه بسازید.** آن توکنی که در گفتگوی ما رد و بدل
  شد فقط برای آزمایش روی لپ‌تاپ بود.
- اگر هرکدام از اینها اشتباه باشد، **سرور عمداً بالا نمی‌آید**. این
  محافظ جای فراموشی را می‌گیرد.

## گام ۵ — کافه‌بازار و پرداخت ⏱ ۳ تا ۷ روز

### ۵-۱. حساب توسعه‌دهنده

در pishkhan.cafebazaar.ir ثبت‌نام کنید. تأیید هویت چند روز طول می‌کشد.

### ۵-۲. اپ را بسازید و آپلود کنید

```bash
cd "/Users/alikavyani/Desktop/speak up/android" && ./gradlew :app:assembleRelease -Pspeakup.apiBaseUrl=https://api.speakup.ir/
```

خروجی: `app/build/outputs/apk/release/app-release.apk`

> اگر گام ۱ را درست انجام داده باشید، این فایل **امضا شده** است. اگر
> اسمش به `-unsigned` ختم شد، یعنی کلید پیدا نشده و باید گام ۱-۲ را
> دوباره ببینید.

### ۵-۳. چهار محصول را تعریف کنید

در پنل کافه‌بازار، بخش خرید درون‌برنامه‌ای. شناسه‌ها باید **دقیقاً**
این‌ها باشند، وگرنه خرید کار نمی‌کند:

| شناسه | عنوان | قیمت (تومان) |
|---|---|---|
| `speakup_1w` | اشتراک هفتگی | ۹۹٬۰۰۰ |
| `speakup_1m` | اشتراک ۱ ماهه | ۲۹۹٬۰۰۰ |
| `speakup_6m` | اشتراک ۶ ماهه | ۷۹۰٬۰۰۰ |
| `speakup_12m` | اشتراک ۱۲ ماهه | ۱٬۱۹۰٬۰۰۰ |

### ۵-۴. توکن دسترسی بگیرید

از همان پنل، و در متغیر `BAZAAR_ACCESS_TOKEN` سرور بگذارید.

### ۵-۵. یک کار برنامه‌نویسی می‌ماند

اتصال به درگاه پرداخت (کتابخانه Poolakey) هنوز نوشته نشده. این را
**من می‌توانم انجام دهم**، ولی تا حساب کافه‌بازار و توکن نباشد قابل
آزمایش نیست. بعد از گام ۵-۴ بگویید تا بنویسمش.
