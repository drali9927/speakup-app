# بریف انتشار — برای برنامه‌نویس بک‌اند

این سند خلاصه‌ی کاریه که برای بالا آوردن سرور تولید `speakup-backend` لازمه.
جزئیات کامل‌تر در `docs/08-چک‌لیست-انتشار.md` هست.

---

## ۱. دامنه

API باید روی این آدرس بالا بیاد:

```
https://api.spkupacademy.com/
```

- دامنه `spkupacademy.com` از قبل ثبت شده (نیم‌سرور: Parspack).
- باید یک **A record** برای ساب‌دامین `api` به IP سرور جدید اضافه بشه
  (از پنل DNS دامنه — دسترسیش پیش صاحب پروژه‌ست).
- روی سرور: **nginx یا Caddy جلوی Node**، با گواهی TLS از Let's Encrypt.
  اپ اندروید فقط HTTPS واقعی قبول می‌کنه؛ HTTP ساده یا self-signed رد می‌شه.

## ۲. اجرای بک‌اند

```bash
cd backend
npm install
npm run build
npm start   # یا با pm2 / systemd برای اجرای دائمی
```

Node نباید مستقیم روی پورت ۴۴۳ باشه — پشت nginx/Caddy با reverse proxy.

## ۳. متغیرهای محیطی سرور (`.env` یا systemd)

```
NODE_ENV=production
JWT_SECRET=<حداقل ۳۲ کاراکتر تصادفی، یک‌بار تعیین می‌شود>
SMS_PROVIDER=kavenegar
KAVENEGAR_API_KEY=…       ← از حساب کاوه‌نگار (دست صاحب پروژه)
KAVENEGAR_TEMPLATE=…      ← نام الگوی ثبت‌شده در پنل کاوه‌نگار
BAZAAR_ACCESS_TOKEN=…     ← از پنل توسعه‌دهندگان کافه‌بازار (دست صاحب پروژه)
```

نکته‌ها:
- `JWT_SECRET` را عوض نکنید بعد از انتشار — عوض شدنش یعنی همه‌ی کاربران
  از حساب‌شان خارج می‌شوند.
- تا وقتی `KAVENEGAR_API_KEY` تنظیم نشده، پیامک ارسال نمی‌شود.
- تا وقتی `BAZAAR_ACCESS_TOKEN` تنظیم نشده، سرور **هیچ** رسید خریدی را
  در حالت production قبول نمی‌کند (این عمدیه، نه باگ).
- `EXPOSE_OTP=1` را در production **ست نکنید** — کد را روی خروجی API آشکار
  می‌کند و فقط برای توسعه‌ی محلی است.

## ۴. دیتابیس

بک‌اند از SQLite استفاده می‌کند (`better-sqlite3`) — نیازی به نصب دیتابیس
جدا نیست. فقط مطمئن شوید مسیر فایل دیتابیس روی دیسک دائمی سرور است (نه
یک container موقتی که با هر دیپلوی پاک می‌شود).

## ۵. تست نهایی

بعد از بالا آمدن سرور:

```bash
curl -I https://api.spkupacademy.com/
```

باید گواهی TLS معتبر برگرداند (نه خطای certificate). بعد از آن اپ اندروید
با همین آدرس (`-Pspeakup.apiBaseUrl=https://api.spkupacademy.com/`) build
می‌شود و تست می‌شود.

---

## آنچه به برنامه‌نویس بک‌اند مربوط نیست

- **کلید امضای اپ اندروید** (`speakup-release.jks`) — قبلاً ساخته شده،
  دست صاحب پروژه می‌ماند. فقط اگر همین فرد build اندروید را هم می‌زند
  لازمش دارد.
- **حساب کاوه‌نگار و کافه‌بازار** — این‌ها باید توسط صاحب کسب‌وکار (نه
  برنامه‌نویس) باز شوند، چون به هویت/کارت واقعی نیاز دارند. برنامه‌نویس
  فقط کلیدهای حاصل از این حساب‌ها را در env سرور می‌گذارد.
