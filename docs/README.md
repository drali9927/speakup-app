# تحلیل محصول LEARNit و طرح ساخت اپلیکیشن مشابه

> سند مرجع پروژه — نسخه ۱.۰ — ۱۴ مرداد ۱۴۰۵ (۲۰۲۶-۰۸-۰۴)

## این مستندات چیست

تحلیل کامل و جز‌به‌جز اپلیکیشن **LEARNit** (بسته `ir.learnit`، نسخه `4.0.13`، build 163) از دید پروداکت منیجر، به‌همراه طرح اجرایی برای ساخت یک محصول هم‌رده با نام و برند جدید.

تحلیل بر پایه دو منبع مستقل انجام شده:

| منبع | روش | خروجی |
|---|---|---|
| تحلیل استاتیک APK | استخراج مانیفست، منابع، رشته‌های متنی، اندپوینت‌ها | معماری، SDKها، سرویس‌های بک‌اند، تاریخچه نسخه‌ها |
| بررسی زنده روی دستگاه | اجرای اپ روی Galaxy Z Fold 2 با ADB، پیمایش تمام مسیرها | ۳۵ اسکرین‌شات، ۳۵ دامپ سلسله‌مراتب UI، جریان‌های کاربری واقعی |

## خلاصه مدیریتی

### محصول در یک جمله
اپلیکیشن آموزش زبان انگلیسی فارسی‌زبان با مدل «دوره ساختاریافته + ابزارهای مکمل»، درآمد از اشتراک، و تمرکز شدید بر نگهداشت روزانه.

### مقیاس ادعایی محصول
بر اساس آنچه خود اپ در صفحه پی‌وال نمایش می‌دهد: **۶+ میلیون نصب**، **۳۰۰+ هزار نظر**، **امتیاز ۴.۸**. این اعداد ادعای خود محصول است و باید مستقل راستی‌آزمایی شود.

### ساختار محصول
پنج ستون که روی یک هسته مشترک (واژه‌نامه + لایتنر + زنجیره مطالعه) سوار شده‌اند:

```
┌─────────────────────────────────────────────────────────┐
│  ۱. دوره ساختاریافته   ۵ سطح CEFR (A1–C1)              │
│     هر درس: Vocabulary · Conversation · Grammar        │
│              · Speaking · Listening · Vocab Review     │
├─────────────────────────────────────────────────────────┤
│  ۲. کتابخانه داستان    Graded readers + ریدر EPUB       │
│                        + دیکشنری هوشمند + صوت           │
├─────────────────────────────────────────────────────────┤
│  ۳. واژه‌نامه + لایتنر  دیکشنری دوزبانه + تکرار فاصله‌دار │
├─────────────────────────────────────────────────────────┤
│  ۴. استاد راهنما (AI)  چت آموزشی با کوتای پیام          │
├─────────────────────────────────────────────────────────┤
│  ۵. دوره‌های ویدیویی    خرید مجزا از اشتراک              │
└─────────────────────────────────────────────────────────┘
   هسته نگهداشت: زنجیره مطالعه (Streak) + یادآور روزانه
```

### مدل درآمدی
| پلن | قیمت | ماهانه معادل |
|---|---:|---:|
| ۱ ماهه | ۵۲۵,۰۰۰ تومان | ۵۲۵,۰۰۰ |
| ۶ ماهه ⭐ پرطرفدارترین | ۸۸۰,۰۰۰ تومان | ۱۴۷,۰۰۰ |
| ۱۲ ماهه 🏷 «۸۰٪ مقرون‌به‌صرفه‌تر» | ۱,۲۵۰,۰۰۰ تومان | ۱۰۳,۰۰۰ |
| VIP پلاس (مادام‌العمر + دوره ویدیویی) | ۴,۹۹۰,۰۰۰ تومان | — |

به‌علاوه ۱۰٪ مالیات بر ارزش افزوده · ضمانت بازگشت وجه ۷ روزه · کد تخفیف · پرداخت از طریق کافه‌بازار.

### مهم‌ترین درس‌های محصولی برای ما

۱. **قلاب نگهداشت قبل از قلاب یادگیری.** زنجیره مطالعه با مکانیزم «فریز» (تا سقف ۳ عدد ذخیره) در بالای هر صفحه دیده می‌شود. این ارزان‌ترین و مؤثرترین بخش محصول است و باید از روز اول در MVP باشد.

۲. **ابزارها، نه فقط دوره.** واژه‌نامه و لایتنر باعث می‌شوند کاربر حتی وقتی درس نمی‌خواند هم اپ را باز کند. اپ‌های صرفاً دوره‌محور این ترافیک را ندارند.

۳. **دیکشنری هوشمند درون متن.** نگه‌داشتن انگشت روی واژه در داستان ← معنی واژه + ترجمه جمله + افزودن به لایتنر. lemmatization هم دارد (`don't` ← `do`). این بهترین بخش تجربه کاربری محصول است.

۴. **دو موتور تشخیص گفتار.** گوگل (آفلاین) + سرویس اختصاصی (آنلاین) + انتخاب خودکار. راه‌حل هوشمندانه برای کاربری که دیتا ندارد یا سرویس گوگل در دسترسش نیست.

۵. **AI به‌عنوان اهرم تبدیل، نه قابلیت رایگان.** استاد راهنما کوتای پیام دارد («۱۰ پیام دیگر») و در پی‌وال به‌عنوان ارزش اصلی اشتراک تبلیغ می‌شود.

۶. **Feature flag از روز اول.** تمام ماژول‌ها با فایل `features.json` و سرویس Flagsmith قابل خاموش/روشن شدن هستند. این یعنی می‌توانند بدون انتشار نسخه جدید، قابلیت‌ها را تست یا غیرفعال کنند.

### نکته حقوقی که باید رعایت شود

این مستندات **نقشه عملکردی و معماری** است، نه کپی محتوا. برای ساخت محصول جدید:

- ✅ ساختار قابلیت‌ها، جریان کاربری، معماری فنی و مدل درآمدی — کپی‌برداری از این‌ها رایج و قانونی است
- ❌ متن دروس، تصاویر، فایل‌های صوتی، دیکشنری، و کتاب‌های داستان — این‌ها دارایی دارای حق تکثیر هستند (بخشی از کتاب‌های داستان هم مالکیت ناشران خارجی مثل Oxford/Cambridge است)
- ❌ نام، لوگو، پالت رنگی و متون بازاریابی
- ⚠️ محتوای آموزشی باید یا تولید اختصاصی شود، یا از منابع با مجوز باز تهیه شود، یا حق نشرش خریداری شود. برآورد این هزینه در [سند رودمپ](06-رودمپ-ساخت.md) آمده است.

- `_analysis/apk/strings_fa.txt` — ۱,۱۲۷ رشته متنی فارسی رابط کاربری
- `_analysis/apk/extracted/assets/` — فایل‌های `features.json` و `change_log.json`
