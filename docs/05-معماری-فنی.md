### نکته: API اصلی روی PHP است
`index.php` در مسیر یعنی هسته بک‌اند PHP است، اما سرویس‌های تخصصی (محتوا، ترجمه، STT) جدا شده‌اند. این یک معماری **تکاملی** است — از یک مونولیت PHP شروع کرده و به‌مرور سرویس‌ها را جدا کرده‌اند.

**برای ما:** لازم نیست از روز اول میکروسرویس بسازیم. با یک مونولیت شروع کن و فقط سرویس‌هایی را جدا کن که مقیاس یا فناوری متفاوت دارند (STT، ترجمه، AI).

## ۵.۳ الگوی «پروکسی اختصاصی» — مهم برای زیرساخت ایران

لاگ‌های OneSignal داخل APK نشان می‌دهد:
```
OneSignalRestClient: Making request to: https://abc.<domain>/api/v1/
```

یعنی به‌جای اتصال مستقیم به `onesignal.com`، اپ به یک **دامنه اختصاصی خودشان** وصل می‌شود که ترافیک را به OneSignal پروکسی می‌کند.

**چرا:** سرویس‌های خارجی از ایران مسدود یا تحریم‌شده‌اند. پروکسی روی سرور خارجی، این مشکل را حل می‌کند بدون اینکه کاربر VPN لازم داشته باشد.

**این الگو را باید کپی کنیم** — برای هر سرویس خارجی (پوش، AI، تحلیل) یک لایه پروکسی روی دامنه خودمان.

مشابه همین برای Firebase: پیکربندی `secondary_messaging` در `features.json` یک پروژه Firebase دوم تعریف می‌کند — احتمالاً استراتژی پشتیبان در صورت قطع دسترسی به پروژه اصلی.

## ۵.۴ مدیریت پیکربندی و Feature Flag

فایل `assets/features.json` داخل APK، پیکربندی **پیش‌فرض آفلاین** است که در زمان اجرا با Flagsmith به‌روزرسانی می‌شود:

```json
[
  { "feature": {"name": "app_properties"}, "enabled": true,
    "feature_state_value": "{ \"term_of_use\": \"...\", \"instagram\": \"...\",
                              \"telegram\": \"...\", \"subscriptions\": \"...\" }" },
  { "feature": {"name": "ticketing"}, "enabled": true,
    "feature_state_value": "{ \"ticket_enabled\": true,
                              \"voice_enabled\": false, \"image_enabled\": true }" },
  { "feature": {"name": "glossary"}, "enabled": true,
    "feature_state_value": "{ \"glossary_enabled\": true, \"leitner_enabled\": true }" },
  { "feature": {"name": "placement_test"}, "enabled": true, ... },
  { "feature": {"name": "library"}, "enabled": true, ... },
  { "feature": {"name": "firebase"}, "enabled": true, ... },
  { "feature": {"name": "streak"}, "enabled": true }
]
```

**الگوی خیلی خوبی است:**
- هر ماژول بزرگ یک flag دارد
- flagها مقدار پیکربندی هم حمل می‌کنند، نه فقط روشن/خاموش
- مقدار پیش‌فرض داخل APK ← اپ بدون شبکه هم کار می‌کند
- لینک‌های شبکه اجتماعی و قوانین از راه دور قابل تغییرند

> 🔴 **اما یک اشتباه امنیتی جدی دارد:** کلید API فایربیس و شناسه OneSignal به‌صورت متن ساده در همین فایل داخل APK قرار دارند و هر کسی می‌تواند استخراجشان کند. **ما نباید این کار را بکنیم** — کلیدهای حساس باید سمت سرور بمانند و از راه کانال امن تحویل داده شوند.

## ۵.۶ مدل داده پیشنهادی

### محتوا
```sql
-- سطوح
CREATE TABLE levels (
  id            SERIAL PRIMARY KEY,
  code          VARCHAR(10) UNIQUE,   -- 'starter','A1','A2','B1','B2','C1'
  title_fa      VARCHAR(100),
  title_en      VARCHAR(100),
  sort_order    INT
);

-- دروس
CREATE TABLE lessons (
  id                SERIAL PRIMARY KEY,
  level_id          INT REFERENCES levels(id),
  number            INT,                  -- شماره درس در سطح
  title_en          VARCHAR(200),         -- 'He is a manager.'
  grammar_topic_fa  VARCHAR(200),         -- 'ضمائر فاعلی و افعال to be'
  is_free           BOOLEAN DEFAULT FALSE,
  estimated_minutes INT,
  cover_image_url   TEXT,
  color_hex         VARCHAR(7),           -- رنگ شش‌ضلعی
  UNIQUE(level_id, number)
);

-- بخش‌های درس
CREATE TABLE sections (
  id                SERIAL PRIMARY KEY,
  lesson_id         INT REFERENCES lessons(id),
  type              VARCHAR(30),  -- vocabulary|conversation|grammar|speaking|listening|vocab_review
  sort_order        INT,
  estimated_minutes INT
);

-- فعالیت‌ها
CREATE TABLE activities (
  id            SERIAL PRIMARY KEY,
  section_id    INT REFERENCES sections(id),
  title         VARCHAR(100),      -- 'Grammar 1', 'Exercise 3'
  description   TEXT,
  activity_type VARCHAR(30),       -- teaching|multiple_choice|free_text|reorder|
                                   -- fill_blank|matching|speaking|listening|flashcard
  sort_order    INT
);

-- آیتم‌ها (سوالات)
CREATE TABLE activity_items (
  id             SERIAL PRIMARY KEY,
  activity_id    INT REFERENCES activities(id),
  prompt         TEXT,             -- 'I am Ali.'
  correct_answer TEXT,             -- "I'm Ali."
  alternatives   JSONB,            -- پاسخ‌های درست جایگزین
  options        JSONB,            -- برای چندگزینه‌ای
  hint_fa        TEXT,
  media_url      TEXT,             -- صوت یا تصویر
  sort_order     INT
);
```

### واژگان و لایتنر
```sql
CREATE TABLE dictionary_entries (

-- نگاشت صورت‌های صرفی به ریشه
CREATE TABLE word_forms (

CREATE TABLE leitner_cards (
  id              BIGSERIAL PRIMARY KEY,
  user_id         BIGINT REFERENCES users(id),
  entry_id        INT REFERENCES dictionary_entries(id),

```

## ۵.۸ استراتژی همگام‌سازی

**اصل: پایگاه داده محلی منبع حقیقت UI است.** هیچ صفحه‌ای نباید منتظر شبکه بماند.

```
     [UI]  ←── همیشه از  ──→  [Room]
                                 │
                                 │ WorkManager
                                 ▼
                          [Sync Engine]
                                 │
                         ┌───────┴───────┐
                    push تغییرات    pull به‌روزرسانی
                         └───────┬───────┘
                                 ▼
                             [Server]
```

**قواعد حل تعارض:**
| نوع داده | قاعده |
|---|---|
| پیشرفت درس | بیشترین مقدار برنده (پیشرفت عقب نمی‌رود) |
| کارت لایتنر | آخرین `updated_at` برنده |
| زنجیره | **همیشه سرور برنده** (ضدتقلب) |
| اشتراک | **همیشه سرور برنده** |
